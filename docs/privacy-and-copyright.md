# Privacy and copyright

Kotoba Vault is designed for personal study material that may include
sensitive notes or content licensed only to the learner.

## What the software does

- Reads local Markdown metadata.
- Moves local files within the configured Obsidian vault.
- Optionally adds a local `reading` property during migration.
- Makes no network requests and sends no telemetry.

## What must not be contributed

- Private or identifying vault content.
- Commercial ebooks or scans.
- Audio or video files.
- Complete third-party subtitle tracks.
- API keys, account identifiers, absolute personal paths, or backup data.

Bug reports should use the smallest synthetic reproduction possible. Future
media and EPUB import tools will process user-provided local files and will not
redistribute source works.
