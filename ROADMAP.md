# Roadmap

## 0.1 — Safe vocabulary organization

- Public repository and initial release.
- Configurable `reading`-driven gojūon sorting.
- Dry-run migration reports and collision checks.
- Synthetic Unicode and kana regression fixtures.

## 0.2 — Import quality

- More frontmatter formats and explicit schema validation.
- Review queue for unresolved readings rather than automatic guessing.
- Reversible migration manifests.

## 0.3 — Media study notes

- Import user-provided VTT/SRT subtitles into timestamped Obsidian notes.
- Preserve millisecond targets while displaying readable timestamps.
- Never download or redistribute source media.

## 0.4 — Reading-friendly text

- Normalize user-owned EPUB-derived Markdown and furigana markup.
- Keep base words intact for linkers and search.
- Provide auditable transformations and synthetic fixtures.

OpenAI-assisted maintainer automation may be added for pull-request review,
Unicode regression generation, issue triage, and release notes. User vault
content will not be used as model input.
